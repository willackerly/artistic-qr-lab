# United Globe Concept

The United globe is unusually well suited to this experiment because the mark is already composed of high-contrast repeated bands / cells that can visually absorb QR structure.

Promising design direction:

- rotate the QR/artwork relationship to align finder geometry with the globe composition;
- preserve finder/timing/alignment anatomy at very high contrast;
- use black or near-black for semantic globe strokes;
- use United-like dark blue for machine-required dark modules that are visually “noise” to a human observer;
- use module rounding / dots for low-saliency code texture while preserving strong module centers;
- search mask, free URL suffix, version, and ECC jointly before spending physical-error budget;
- use Intelligent Repair to preferentially restore visually unimportant blue/noise modules before damaging the globe's defining arcs.

A short redirect URL is especially useful because an intentionally larger QR creates a large number of excess data-capacity positions. Standard pad bytes are not arbitrary free variables, but semantically ignored suffix bytes can provide standards-compliant steering space; experimental pad-byte control is useful for research.
